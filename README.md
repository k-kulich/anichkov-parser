# anichkov-parser
Parser for Anichkov Lyceum (11th grade individual project)

## Installing
Install full package or **parser.exe** with folder **db** only.

## How to start
Run **parser.exe** or **main.py**. Then you will need to enter the VK API token (user access token: https://dev.vk.com/ru/api/access-token/implicit-flow-user#Открытие%20диалога%20авторизации). This token provides VK parsing, so you may skip this part if you don't need it.

Then program starts.
